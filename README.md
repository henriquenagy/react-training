# Socratic Training: React Fundamentals

Repository dedicated exclusively to solving batches of practical exercises (Drills) to consolidate the logic and main React Hooks.

**Methodology:**

- Guided resolution without the initial use of AI for code generation.
- Focus on repetition and building technical intuition ("glancing and knowing what to use").
- Use of pure JavaScript/React (no complex styling or routing frameworks at this stage).

**Training Modules (React's 80/20):**

1. The Trigger (`useState` + Events)
2. The Loop (`.map()` + `key`)
3. The Sieve (`.filter()`)
4. Immutable Memory (Spread Operator `...` in Arrays and Objects)
5. Putting It All Together
